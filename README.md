# Context Cart

A modern, responsive e-commerce storefront built with React, TypeScript, and Tailwind CSS. 

## Features
- **Product Catalog:** Browse diverse products with dynamic routing and breadcrumbs.
- **Search:** Live debounced search functionality.
- **Shopping Cart:** Persistent local storage cart with quantity limits and visual feedback.
- **UI/UX:** Sleek, minimal dark-mode design system with micro-animations.
- **Authentication:** Simulated local-storage based user sessions.

## Tech Stack
- React + Vite
- TypeScript
- Tailwind CSS v4
- React Router DOM
- Axios (DummyJSON API)

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```
